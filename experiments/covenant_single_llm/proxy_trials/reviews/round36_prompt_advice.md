There is concrete technical evidence of two imperfectly matched publication surfaces. A00's saved file has two literal backslash-n-plus sequences; B00 has seven literal backslash-n sequences. More decisively, the [public delivery audit](../candidate_35/publication_delivery_audit.json) finds nine of twelve file/final pairs differ before the declared formatting normalization, while all twelve have the same words afterward. The hypothesis to test is narrower and prospective: **requiring file production and repetition while composing a new passage affects the fiction the author chooses, and removing that obligation improves the sustained dialogue without sacrificing scene substance or boundaries.** Perhaps the artifact task changes what the author treats as a finished performance; perhaps it has no literary effect at all. The escaped newlines justify attention to delivery, but do not prove either account. This intervention changes file-writing and duplicate emission together. It would estimate the practical effect of removing that combined obligation, not isolate which part caused a gain.

First-passage task framing and accumulated conversation exposure must remain separate claims. The poised exchanges already appear in both C35 openings, before either author has prior published story turns to imitate. Earlier repeated prose therefore cannot be the sole cause of those opening exchanges. On later persistent turns, the saved passage may also have appeared in a public tool command as well as the final answer. The inspected requests establish the two-output demand; this report does not audit the exact retained model context or infer it from private reasoning. A fresh-author screen tests composing under that demand, including any within-task effects. It does not test a growing number of duplicated earlier turns.

The actual loop is short. A fresh author reads the frozen task and packet, composes the whole passage, then fulfills its assigned delivery contract. In the control it writes the passage and returns it; in treatment it returns it. The root captures the exact public final answer into an artifact after that answer exists. Capture is a technical copy, not a writing task, selection step or revision request. Each sample uses one author request; there is no draft-and-edit loop. Independent samples need not wait for one another, but capture waits for each answer and retrospective review waits for the frozen outputs. Nothing here establishes API latency, cache behavior or cost.

For the primary literary comparison, use the captured public final answer in **both** conditions. Otherwise a cleaner return-only display could masquerade as better composition merely because the control was scored from its more damaged file. Also preserve the control's author-written file and audit its agreement with the final answer as a separate delivery measure. If the two have different words, retain both and report the violation; do not select the better one. Copy final text without rewriting punctuation, decoding literal escape sequences, removing content or normalizing whitespace. Store any comparison normalization separately. This arrangement tests prospective task effects rather than retroactively choosing a better C35 surface.

A missing final answer, unauthorized reading, failure to read the full packet, or treatment fiction written through tools is a recorded execution/compliance problem. Do not ask that author for another passage and quietly treat the retry as the first sample. If a clean comparison cannot be obtained, its evidentiary limit should be explicit. An artifact-copy failure can be recovered by copying the already completed public answer, without asking the author to generate again.

**Judgment and counterevidence.** Lock the root review before seeing an independent review. Give the independent reviewer anonymously labelled complete outputs and the complete authoritative context for each block, without delivery instructions, condition labels or root ratings. Review all outputs, not just the most promising repeat. Ask for the existing five dimensions and concrete evidence of whether exchanges sustain particular interests, relationships and activities without repeatedly becoming prepared corrections. Preserve disagreements. Anonymous provenance reduces bias; it does not guarantee that formatting cannot make a condition guessable.

For this small screen, I would advance the intervention only if both reviewers find a substantive return-only advantage in both context blocks, with both return-only repeats in each block retainable at prose/dialogue four or above and no material loss elsewhere. That is a conservative screening rule, not a statistical estimate or a change to the established full-session selection protocol. A tied control, mixed repeats, or reviewer disagreement would be inconclusive for promotion. This pilot cannot select a candidate; the existing requirement for two fresh substantial sessions remains.

The following would count against the proposed literary hypothesis: the return-only passages retain the same cumulative reply pattern; any preference disappears when comparing public finals in both arms; improvement consists only of correct line breaks, fewer words or fewer participants; or the prose becomes plainer by summarizing away the social activity. Loss of independent purpose, inaccessible knowledge, new player-authored speech, contradictory game/state outcomes, or a forced ending also defeats a useful gain. A formatting-only improvement is a legitimate delivery finding, but should be reported as such.

A null first-output screen would weaken the immediate task-framing hypothesis in these contexts. It would not settle the separate accumulated-duplication hypothesis, because no author in this pilot has prior experimental turns in its own conversation. Conversely, better fresh outputs would not prove that the advantage survives persistence. A later session comparison would need to retain the assigned delivery mode across turns and acknowledge that its generated histories diverge; it would assess the practical loop, not isolate repeated text from every other history effect.

The proposed change is therefore small in scope but materially different from the preceding verbal guidance experiments: remove an untested author obligation, keep the complete story context, and compare new fiction on the same public-answer surface. No prompt promotion, production machinery, biography reduction, fictional example or model change is warranted by this advisory report.
