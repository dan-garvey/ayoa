# Prompting guidance for the Terra experiment

Checked official online documentation on 2026-09-14 UTC, preserving the requested
`gpt-5.6-terra` target. This is focused documentation lookup, not exhaustive
research or a demonstrated explanation of the model's literary weaknesses.

The [GPT-5.6 family guide](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.6#prompting-best-practices)
recommends deduplicating instructions, concrete style requirements and testing
whether brevity constraints help. Its reported prompt-simplification gains are
from coding evaluations, not storytelling.

The [Terra model page](https://developers.openai.com/api/docs/models/gpt-5.6-terra)
confirms that Terra belongs to this family and supports maximum reasoning.
No Terra-specific fiction recipe was found in the focused official-domain
searches. Results about GPT-6 Astra and older model families were not substituted
for Terra evidence.

The [general reasoning guidance](https://developers.openai.com/api/docs/guides/reasoning-best-practices#how-to-prompt-reasoning-models-effectively)
recommends direct instructions, trying without examples first, and avoiding
unnecessary instructions to expose step-by-step reasoning. Much of that page
uses older o-series examples, so it is supplementary context, not Terra-specific
literary evidence.

Our next hypothesis is a simpler reusable story contract: preserve player
ownership, asymmetric character knowledge, consistent invented history and
adaptive initiative; specify the reading experience without scripting speech
patterns, miniature scenes or a fixed word range. The earlier compact C13
screen did not succeed, so shorter alone is not assumed to solve the problem.

The user explicitly rejected character-specific dialogue examples because they
could fix characters into one speech pattern and would not scale to other story
briefs. That proposed direction was abandoned before any candidate was written.
The new common prompt will contain no character names or dialogue examples.
Covenant facts and character substance remain available in the separate brief.

Keep Terra at maximum reasoning and retain the same artifact wrapper for this
test. Proxy authors still have coding-agent instructions and tools; documentation
about direct API verbosity, persisted reasoning or pro mode does not establish
those settings for these proxy calls. No API or model change is part of this test.
