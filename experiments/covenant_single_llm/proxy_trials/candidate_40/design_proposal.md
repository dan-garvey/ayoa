The planned scope is four fresh whole-story authors, two per context. Each produces an opening and two successive social continuations, for twelve publications and twelve author requests. The initial response begins in the player's room before supper. The next submission brings the player downstairs to introduce himself and eat/listen for a few minutes. The final submission continues eating and listening for a quarter hour. Both contexts use exactly the same two social submissions and the same player conduct. Context-specific initial place names and player-background facts differ openly. The player can choose quiet despite an NPC's question; resulting social awkwardness is permissible and should be assessed, not repaired with invented player speech.

Each author receives the complete story brief and player persona, then retains its own published conversation for the two follow-ups. Root captures each exact first public final before sending the next frozen submission. No editor, scene outline, separate character agent, selection, reroll or tailored criticism is used. New consistent history is allowed; an unshared secret still requires a plausible source before a character can use it. Ordinary meal actions are delegated; new player speech, private reactions and consequential decisions are not.

All twelve outputs are required for the diagnostic unless an external execution failure prevents them. Complete source and publication read/capture audits accompany a root full-sequence review locked before an independent provenance-anonymized review. Reviewers score prose/dialogue, character distinction, independent interests, direction and adaptive initiative, using the existing3/4/5 meanings. They judge the connected dinner passages, not just attractive openings, and preserve local failures and ambiguity. Both settings are identifiable in their fiction; anonymized run labels do not make this a blind setting comparison.

There is no automatic promotion gate. If both second-setting sequences are retainable in their dinner exchanges for both reviewers and Covenant is not, the result supports investigating context dependence while preserving rich backgrounds. If both settings improve, fresh starts and route variation remain live explanations. If both reproduce the pattern, a Covenant-only explanation weakens without identifying a model ceiling. Mixed repeats are inconclusive. A short diagnostic never satisfies the broader requirement for two substantial different-policy sessions, held-out boundary cases and retained quality through consequences.

The unmatched variables must be frozen explicitly before seeing any output: genre, world complexity, institutional status, character ages/roles, supernatural speech rules, the source author's portrayal guidance, available topic/relationship material, and prompt length. The same ensemble size and quiet player policy control only some differences. The result cannot attribute an effect to any one unmatched feature, establish API equivalence, or justify removing rich histories.
